# Brag Plan: VantageAudit

## What is this app?
VantageAudit is an autonomous, regulatory financial filing auditor that reads visual 10-K HTML statements, runs dual consensus extraction (rules + visual LLM), validates balance sheet equations, and executes durable human-in-the-loop state triage backed by SQLite checkpointers and cryptographic SHA-256 audit logs.

## The angle
High-finance certainty meets cutting-edge cybernetic intelligence. Financial models hallucinate; VantageAudit proves every number with dual consensus, catches injected chaos, and never loses state when rebooted mid-run.

## Hook (first 2-3 seconds)
A stark obsidian screen with glowing gold circuit hairlines and bold kinetic text:
"10-K FILINGS LIE.
OR AT LEAST, MODELS DO."
Then an immediate snap to the VantageAudit 3D Supernova consensus core.

## Key moments (the middle)
- **Moment 1: Two Extractors. One Truth.**
  Dual consensus comparison card revealing Rules Extractor ($94.9B) vs LLM Visual Extractor ($94.9B) matching at 100% confidence.
- **Moment 2: Four Checks. Every Time.**
  Staggered animated flash of the four invariant tests: Accounting Equation, Segment Reconcile, YoY Fluctuation, Cross-Statement Balance.
- **Moment 3: Killed Mid-Run. Nothing Lost.**
  Hard crash recovery simulation: run interrupted, state checkpointed to SQLite, re-opened with 0 duplicate network LLM calls.

## Outro / punchline
"AUDIT AT MACHINE SPEED. CERTIFY WITH HUMAN TRUTH."
Final snap to the VantageAudit v2.0 emblem with live telemetry counter (`100% POST-REVIEW ACCURACY`).

## User flow worth showing
1. Ingest SEC 10-K HTML table from EDGAR
2. Auto-detect anomaly & pause on durable `interrupt()`
3. Human reviews and approves with a single keystroke `[A]`
4. Sequential SHA-256 hash appended to immutable ledger
